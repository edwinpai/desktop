# EdwinPAI Desktop Campaign Messaging (v1)

## Core Positioning
EdwinPAI Desktop is the easiest way to run EdwinPAI: install it like any normal app on Mac, Windows, or Linux, then follow guided setup to get your assistant live in minutes.

## Primary Promise
**From download to working assistant in minutes — no DevOps required.**

## Audience
- Founders and operators who want execution, not chatbot demos
- Solo builders automating daily workflows
- Teams that need practical AI across tools and channels

## Key Differentiators
1. **Native desktop app** for Mac, Windows, Linux
2. **Setup wizards** that guide you step-by-step
3. **Real workflow execution** (not just conversation)
4. **Control and configurability** for power users

## Objection Handling
- "Too technical to set up" → Wizard-driven onboarding removes complexity
- "Another AI chat app?" → EdwinPAI is built to execute workflows, not just answer questions
- "Will this lock me in?" → Local-first control and configurable integrations
