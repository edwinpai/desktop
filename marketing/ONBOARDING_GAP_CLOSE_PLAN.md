# Onboarding Gap Close Plan (Desktop-First, No CLI Default)

## Problem
Marketing promise: easy desktop install/setup.  
Reality: advanced flows still require technical steps.

## Goal
Default new user path requires **no CLI** to reach first useful automation.

## Phase Plan
### Phase 1 — Minimum Desktop Path
- Download/install app
- Sign in/connect model
- Guided wizard for first channel/tool
- Run first automation template

### Phase 2 — Failure Recovery UX
- In-app diagnosis for auth/env/model issues
- One-click fix suggestions
- Human-readable errors

### Phase 3 — Migration/Power User Escalation
- Keep CLI as optional advanced lane
- Provide "open advanced" from GUI

## KPIs
- Median time-to-first-automation < 15 min
- >80% completion rate for guided setup
- <10% users requiring CLI in first session
